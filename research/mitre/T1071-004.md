# T1071.004 — DNS as an application-layer channel

DNS is the protocol most likely to be allowed outbound from a network
that blocks everything else, which is exactly why adversaries use it for
command and control and for exfiltration. The query name is an
attacker-controlled field that reaches a server the attacker owns, and
the response is a channel back.

## Why sloth cites this

Six alerts sit on this technique and its neighbours, and they detect
four distinguishable shapes:

**Volume in the name.** `DNS_TUNNEL` watches for query names carrying
more entropy and length than a hostname needs. A tunnel has to move
bytes, and the only field with room is the label.

**Failure as a side effect.** `NXDOMAIN_BURST` — a burst of
non-existent-domain answers — is what a tunnel or a DGA produces
incidentally: names generated rather than resolved mostly do not exist.

**Generated names.** `DGA_DOMAIN` (T1568.002) scores the name itself.
Malware that hard-codes a C2 address dies when that address is seized;
malware that generates candidate names each day does not.

**Regularity.** `BEACONING` (T1071) watches the *interval* rather than
the content. A human-driven session is bursty; an implant checking in is
periodic, and periodicity survives encryption.

`THREAT_DOMAIN` and `THREAT_IP` are the matcher rather than the
heuristic: a name or address on a list someone else compiled.

## What it does not say

**Encoding is not exfiltration.** Long, high-entropy DNS names are also
how several content-delivery and anti-abuse systems work normally. The
detector reports a shape, not an intent, and on a network using such a
service it will report it repeatedly.

**A DGA score is not a verdict.** Some legitimate domains score badly —
short random-looking names are a naming fashion, not a signal by
themselves — and some real DGAs use wordlists that score well.

**Threat-intel lists go stale in both directions.** An address is
re-allocated; a domain is sinkholed and becomes a *good* thing to see
resolved. A match says the indicator was on a list, not that it is
currently hostile.

**Periodicity is not malice.** Update checkers, telemetry and NTP-like
services beacon by design. What makes an implant's beacon interesting is
the destination, not the rhythm — which is why `BEACONING` is worth
reading beside `THREAT_IP` rather than alone.
